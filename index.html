ai-native

Personal services on ai-native.japaneast.cloudapp.azure.com. Everything below runs on a single Azure VM behind one Nginx.

Blog /myblog

Hexo static site. Notes on what's running here, deployment write-ups.
ai-feed /feed

Daily AI-frontier digest. A Claude-Code agent aggregates ~10 sources twice a day and writes an opinionated synthesis. Public read; AI-explain needs sign-in.
ai-playground /chat sign-in

Private chat UI against Azure AI Foundry models (Llama 3.3, etc.). GitHub OAuth, allowlist.
vpn-monitor /vpn sign-in

Hysteria2 VPN dashboard — active connections, cumulative traffic, geo-resolved connection log.
Traffic report /traffic

GoAccess HTML report parsing the Nginx access log. Refreshes every 5 min.
status /status

Feature-health dashboard. Application-level checks (digest freshness, VPN pipeline, cert expiry, disk pressure). Companion to external UptimeRobot.
cost /cost

AI spend tracker. Logs every Claude Code agent run and every Foundry call to Postgres, aggregates by day / service / model.
stock /stock

MSFT analysis dashboard. Daily LLM-driven outlook (bullish/neutral/bearish + drivers + risks) over a 90-day price timeline. Decision support, not advice.
youtube-clips /youtube-clips

Profile-based multi-platform video remix pipeline. Agent searches source platforms for raw material, drafts a target-language commentary, renders YouTube/Bilibili/抖音 variants. You upload manually.
quit-diary /quit-diary

WeChat mini program backend. 离职日记 — private daily journal for people who want to quit but haven't. Template prompts + quit-cost calculator + personal stats. No community, no sharing.
Umami /umami sign-in

JS-snippet pageview analytics. Self-hosted Umami v2, rebuilt with BASE_PATH baked in.

Single Azure VM (Japan East, B2s). Nginx + Let's Encrypt + 5 docker services. Source for most of these lives at github.com/WhatsFish.
